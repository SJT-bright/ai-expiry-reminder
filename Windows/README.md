# AI 到期提醒 · Windows

从项目 [最新发布页](https://github.com/SJT-bright/ai-expiry-reminder/releases/latest) 下载对应架构的 `Setup.exe`，或解压便携版 ZIP 并打开 `AI到期提醒.exe`。安装包已包含运行环境，无需另装 Node.js、Python 或数据库。

支持 Windows 10 / 11 x64 和 Windows 11 ARM64。Windows 11 使用 Acrylic 背景，旧系统使用半透明背景。Mac 版继续使用原生 Swift / AppKit 和 macOS 26 液态玻璃。

## 使用

- 点击右上角 54×18 倒计时胶囊展开；拖动胶囊或沙漏移动。顶部 ＋ 添加记录，⚙ 管理记录，⌃ 收起。鼠标移开 8 秒自动收起，可取消勾选。
- 一次性到期只记录订阅；周期额度支持固定小时、每周固定日、每月固定日和订阅日。固定周期按原重置时刻滚动，不从当前时间重新计算。
- 周额度分组从填写的首次重置时间每 7 天生成，最多 520 轮。已过去的轮次跳过，远期轮次保留在数据库。编辑某周会在订阅边界内同步后续周，失败时整笔事务回滚。
- 右键悬浮行 → 提前提醒，或在管理页点“提醒”，按天＋小时填写。默认提前 5 小时；提前量必须小于额度周期。5 小时窗口可设置提前 2 小时。
- 系统托盘提供展开、管理、刷新、归位和退出入口。常驻开关同时管理开机启动和崩溃后恢复；“彻底退出”可关闭本次常驻，关闭开关则后续不再自动启动。
- 管理页的展示天数只影响可见范围，远期记录仍在库中。过期 3 天归档，一次性订阅归档 30 天后清理前会备份；重置规则残缺的窗口保留供修正。

## 本地数据与备份

正式数据位于 `%APPDATA%\AI到期提醒\`，与安装路径分开。升级和卸载均保留该目录。`data.sqlite` 使用 WAL 和事务，`state.json` 保存显示与常驻设置。

启动已有数据时，以及删除、分周转换、导入和归档清理前，自动在 `backups` 保留 SQLite 一致性副本。管理页的“备份”可额外保存一份；“导出”生成 JSON，包含手动记录及其提前量，不包含登录凭据。导入会先备份当前库，再按 ID 合并，不清空其他记录。

“导入”支持本应用 JSON 和 Mac 版 SQLite 备份。请先在 Mac 上生成 SQLite 一致性备份，不能只复制正在运行的 WAL 数据库主文件。单条自定义提前量按 `reminder_settings` 导入；缺少设置时继续采用默认 5 小时。跨端不会同步登录或账号。

## 官方本地读取

Codex / ChatGPT 从用户目录 `.codex/auth.json` 的订阅声明及 `.codex/sessions` 的官方 `rate_limits` 读取；支持多个额度池、数字字符串和等待新窗口上报的状态。Claude 的 5 小时窗口由本地活动估算，明确标注“非官方”。Grok 和 ZCode 的登录/缓存只说明是否检测到，不伪造服务端到期时间，订阅和重置卡请手动添加。读取在后台线程完成，不发网络请求、不修改这些源文件。

## 开发与验证

使用 Node.js 24+：

```powershell
cd Windows
npm ci
npm test
npm start
npm run dist -- --x64
npm run dist -- --arm64
```

测试入口 `node test/native-smoke.cjs` 在独立临时数据根内操作真实渲染界面，并检查保存、取消、无效输入、提醒设置、重新打开、备份恢复、窗口尺寸和管理列表。传入打包后的 EXE 路径可验证实际发布程序。GitHub Actions 分别在原生 x64 / ARM64 Windows runner 构建和运行，另检查安装与卸载保留数据。

测试或临时预览可通过 `AR_DATA_DIR` 指定独立数据目录，正式运行不要设置它。发布不包含任何本机数据。Windows 安装包目前没有代码签名，Mac 包为临时签名、未公证；系统可能提示来源未验证。

在 Mac 上运行 Windows 开发预览时，默认使用独立的 `AI到期提醒-Windows预览` 数据目录；正式 Mac 应用继续使用自己的数据目录。

Windows 原生宿主受系统最小窗口高度限制，可见胶囊仍为 54×18；宿主多出的区域透明并透传鼠标。验收分别检查可见胶囊和原生宿主尺寸，不能用网页尺寸冒充原生窗口边界。

构建入口固定使用安装解码器支持的 BCJ 压缩过滤器，避免 electron-builder 26.15 的 [ARM64 安装后丢失 EXE / DLL 问题](https://github.com/electron-userland/electron-builder/issues/9983)。请使用 `npm run dist`，让构建和安装检查采用相同配置。
