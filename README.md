# ⏳ AI 到期提醒

一个本地运行的悬浮提醒工具，实时展示 AI 订阅与额度窗口的**到期时间倒计时**。Mac 版使用原生 Swift / AppKit；Windows 版提供包含运行环境的 x64、ARM64 安装包和便携包。

平时它吸附在**屏幕右上角边缘**，是原尺寸 54×18 的玻璃胶囊，显示最近到期项；点击才展开成紧凑面板；鼠标离开 8 秒后自动收回药丸状态。添加 / 编辑 / 删除都在**设置后台**或面板内完成。

## 功能

- **玻璃胶囊**：54×18，倒计时使用完整内宽并按长度适配字号，颜色表示紧急程度；空库显示“暂无记录”。点击松开时展开，拖动移动位置，拖动不会误展开。
- **紧凑展开面板**：点击药丸展开（240pt 宽）。每行 = 状态点 + 名称 + 倒计时（右对齐）+ 小字「供应商 · 到期时间 · 来源」。无多余留白。
- **颜色规则**：剩余不足 24 小时 → 红色；过期超 1 天 → 转灰（过期满 3 天不再显示，见「过期自动处置」）；额度用尽 → 白色；其余绿色。
- **自动读取官方本地数据**（无网络请求）：
  - **Codex / ChatGPT**：从 `~/.codex/auth.json` 的官方 JWT 读出**订阅到期日**；从最新会话的官方 `rate_limits` 读出**额度窗口重置时间**（5 小时窗口 / 周窗口，含已用百分比）。
  - **Claude Code**：检测 `~/.claude`，按本地会话活动**估算**当前 5 小时窗口重置时间。
  - **ZCode**：检测 `~/.zcode`，读其本地配额记录。
  - **Grok**：检测 `~/.grok` 登录状态（其 CLI 不落盘限流数据，重置卡/订阅请手动添加）。
- **手动记录任意订阅**：Grok 重置卡、中转站、各种会员——买了立刻记一笔。支持**周期窗口自动滚动**（如 5 小时窗口到期自动滚到下一轮）。
- **玻璃日期选择器**：添加、编辑及行内调整日期时，点日期框右侧的日历图标即可选日；时间仍可直接键入。非法日期会被拦截，也可打开日历重新选择。
- **明确的记录类型**：一次性到期只保存订阅，不自动猜测额度。周期额度支持每周 7 天、固定每 30 天和 5 小时；编辑其他旧周期时保留原值。订阅周额度按明确填写的首次重置时间每 7 天拆分，最多 520 条；首次日期默认保留已填写的到期锚点，请按实际重置日调整。分周转换在事务中完成，失败时保留原记录。表单底部实时显示**完整排期与计算性建议**：自动填补每一轮重置日期（这次 / 下一次 / …… / 最后一次）；首轮不足 7 天提示「这几天快点用」；末轮叠不满订阅到期时给出白嫖天数与续买建议（再等几天再买新会员，避免额度重叠）。
- **逐条设置提前提醒**：右键列表中的记录 →「提前提醒…」，按「天＋小时」填写（例如提前 2 天 3 小时），可预览提醒时刻、保存或取消，也可一键恢复默认提前 5 小时。每条独立持久保存，手动记录与官方记录都支持；修改不会改变到期时间或其他周次。到达各自的提前量时，合并弹出居中的模态提醒。周期额度的提前量必须短于其周期，默认不提醒 ≤5 小时的短窗口；5 小时窗口可改成提前 2 小时。提醒不受面板展示天数限制；同一个到期瞬间在进程内只弹一次，重开后可能再弹一次。
- **过期自动处置**：过期满 3 天的条目不再出现在面板（与颜色规则的宽限期同一口径）。手动订阅打上归档时间（设置后台仍可见可清理），归档超 30 天自动从库中清除；**重置规则残缺、算不出下一轮的额度窗口只归档不删除**（那是用户手录、还在消耗的活额度，删了不可恢复）。官方条目不入库，按同一宽限期在界面隐藏。悬浮窗常驻右上角本身就是提醒，不再弹系统通知、不接飞书。
- **胶囊内控制区**：点击 Dock 图标或在本应用中按 ⌘1，会在原胶囊面板内展开控制区。列表顶部的 ⚙ 可开关控制区；“收起、归位、管理、更多”排在一行。“更多”可暂时隐藏悬浮窗或恢复顶部菜单栏入口，隐藏后再次点 Dock 图标即可恢复。列表和控制区共用同一块液态玻璃，收起后仍是 54×18 胶囊，提醒继续运行。自动收起开关按原设置保留。⌘, 打开管理记录，没有全局快捷键。

## 快速开始

从 [最新下载与分享页面](https://github.com/SJT-bright/ai-expiry-reminder/releases/latest) 选择对应平台。

| 平台 | 下载 | 使用方式 |
|---|---|---|
| macOS 26+，Apple Silicon / Intel | `AI-Expiry-Reminder-1.4.0-macOS26-universal.zip` | 解压，将 `AI到期提醒.app` 放入“应用程序” |
| Windows 10 / 11 x64 | `Windows-x64-Setup.exe` 或 `Windows-x64.zip` | 运行安装程序，或解压打开 `AI到期提醒.exe` |
| Windows 11 ARM64 | `Windows-arm64-Setup.exe` 或 `Windows-arm64.zip` | 下载 ARM64 版本，使用方式相同 |

Windows 版无需另装 Node.js / Python；完整说明见 [Windows/README.md](Windows/README.md)。Mac 包为临时签名、未公证，Windows 包暂未代码签名。发布包不包含任何本机订阅记录或登录数据。

```bash
./build.sh          # 编译并打包为 build/AI到期提醒.app（仅需 macOS 自带 swiftc，无第三方依赖）
open "build/AI到期提醒.app"
open "build/AI到期提醒.app" --args --settings   # 启动时直接打开设置后台
```

运行要求：macOS 26+（界面用系统液态玻璃 `NSGlassEffectView` / `NSBezelStyleGlass`，均为 macOS 26 公开 API，不再保留毛玻璃退路）。编译需安装包含 macOS 26 SDK 的 Xcode Command Line Tools（`xcode-select --install`）。

## 常驻机制

应用默认以 **LaunchAgent 常驻**（`~/Library/LaunchAgents/com.sijunting.ai-expiry-reminder.plist`）：

- **登录自启**（RunAtLoad）
- **被杀/崩溃自动重启**（KeepAlive=true，`ThrottleInterval=2` → 强杀后约 2 秒拉起；连续崩溃循环期受该节流约束）
- 菜单「退出」在常驻模式下也会被自动重启——这是设计行为；**彻底关闭**请先在设置里取消勾选「常驻」，应用会以不受守护模式重启一次
- 单实例：pid 文件上的 `flock` 互斥锁（内核随进程释放，不需要清理残留），接管前先校验对方 bundle id / 可执行路径，确认是本 App 才发信号
- agent 实例的日志输出到 `~/Library/Application Support/AI到期提醒/logs/agent.out.log` 与 `agent.err.log`（stdout / stderr 分文件，无轮转）

菜单栏 ⏳ 和设置后台的「常驻」开关可安装/移除该 LaunchAgent。

## 数据与文件

- 条目：`~/Library/Application Support/AI到期提醒/data.sqlite`（WAL）；设置：同目录 `state.json`
- 单条提前量保存于 SQLite 的 `reminder_settings` 表，以条目 id 关联；没有设置的记录自动沿用 5 小时，保留原有 `items` 数据。
- 官方数据每 60 秒自动重新读取（只读会话文件尾部窗口，不整文件读入）；「剩余」不足 24 小时在界面标红，过期超 1 天转灰，过期满 3 天不再显示。
- 悬浮窗置顶显示，支持所有桌面、全屏应用与台前调度；⌃ 收起为原尺寸胶囊。点击 Dock 在原胶囊内展开控制区，选择“归位”可收起并回到胶囊所在屏幕的右上角；右键沙漏也有恢复和隐藏入口。
- 设置后台的列表行与按钮支持悬停浮起、移开回落，快速往返从当前位置连续过渡；遵循系统“减弱动态效果”。底部常驻、数据文件夹和展示天数排在一行，窗口可见高度更紧凑。

## 如何接入新的官方数据源

在 `Sources/Readers.swift` 中实现 `SourceReader` 协议并注册到 `ReaderEngine.all`：

```swift
final class MyProviderReader: SourceReader {
    let name = "MyProvider"
    func read() -> ReaderResult {
        // 读取本地配置 / 会话文件，解析出到期时间
        return ReaderResult(items: [/* SubItem(...) */], status: "已读取 N 项")
    }
}
```

`SubItem` 关键字段：`expiresAt`（到期时间）、`kind`（`.subscription` 一次性 / `.window` 周期滚动）、`repeatHours`（周期小时数）、`purchaseAt`（购买时间，推断输入）、`archivedAt`（归档时间）。表单采用明确的类型与首次重置日期。`Store.saveInferred` 为历史兼容接口，不作为新增一次性记录的入口；厂商候选规则不能代表某一账户的真实重置时刻。

## 已知限制 / Roadmap

- Grok 官方限流数据本地不可读，当前为手动记录；后续可接官方接口。
- Claude 的 5 小时窗口为本地会话估算，非官方精确值。
- ChatGPT 订阅到期日来自 Codex CLI 本地缓存，长期不使用 Codex 会滞后（跑一次 Codex 即刷新）。

## 交互验收

顶部系统菜单栏显示沙漏和「到期」文字：点击打开系统菜单，再选「展开胶囊控制」可打开同窗控制区。入口不见时，在「系统设置 → 菜单栏 → 允许在菜单栏显示」开启「AI到期提醒」，再从胶囊控制区的「更多」中点「恢复顶部菜单栏图标」；应用菜单也提供同名命令（⌘2）。此操作只恢复菜单栏入口。「桌面悬浮窗归位」单独负责桌面窗口的位置。

Mac 版为原生 AppKit，Windows 版为 Electron 桌面应用；两端都只读取本地官方缓存，没有云端同步或 AI 推理接口。Mac 桌面交互用原生 E2E 工具操作，Playwright 不适用于 AppKit 窗口。业务存储测试包括正常写入、异常写入、关联同步失败、事务回滚和周期边界；Windows 原生构建和打包验收由 GitHub Actions 完成。

## 跨平台版本 1.4.0

Mac 保留 54×18 原尺寸胶囊、液态玻璃日期选择、同窗控制区、单条提前提醒、分周与周期管理、本地数据读取和常驻开关，构建输出同时包含 arm64 / x86_64。Windows 提供对应的记录、周期、分周、提醒和本地读取流程，以 Windows Acrylic / 半透明背景适配悬浮窗与管理页，并增加备份及跨端导入入口。

Windows 数据目录为 `%APPDATA%\AI到期提醒\`，Mac 仍为 `~/Library/Application Support/AI到期提醒/`。数据留在各自设备，不随安装包分享。Windows 的导入入口可以读取 Mac 的 SQLite 一致性备份；不能只复制正在运行的 `data.sqlite` 主文件，以免遗漏 WAL 中的新记录。

`./test_ui_e2e.sh` 构建独立的“AI到期提醒验收.app”，供原生桌面工具操作；它使用 `build/ui-acceptance-data` 隔离数据，不接管正式实例。此脚本只构建验收入口，不代表端到端测试通过。实际测试过程与未验证边界见 [UI_ACCEPTANCE.md](UI_ACCEPTANCE.md)。
